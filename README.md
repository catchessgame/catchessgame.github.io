# Cat Chess website

Static site for Cat Chess, served by GitHub Pages.

- `index.html`: landing page. Tester sign-up links are the `LINKS` object at the bottom.
- `privacy/`: privacy policy (the URL used in the Play Console).
- `app-ads.txt`: AdMob seller file; must stay at the site root.
- `img/`: art rendered from the game (`tests/site_art.gd` in the cat-chess repo).
